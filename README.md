# keywordIG — автоответчик на комментарии и сообщения Instagram

Человек пишет под постом кодовое слово — получает публичный ответ под своим комментарием
и обещанный материал в директ. Пишет то же слово в директ — получает ответ в диалоге.
Правила и тексты задаются в панели установки, без правки кода и без SQL.

Это **репозиторий, который вы разворачиваете у себя**: свой сервер, свой домен, своё
приложение Meta, свой аккаунт Instagram. Не сервис, не подписка, не SaaS. Пакет ничего
и никуда о себе не сообщает: ни телеметрии, ни обращений к автору.

Внутри: FastAPI (приёмник вебхуков, диспетчер очереди, панель установки), Postgres, Caddy
с автоматическим TLS. Поднимается одной командой, проверяется другой.

## Кому это подойдёт

Владельцу одного профессионального аккаунта Instagram, у которого под постами регулярно
пишут кодовое слово ради материала, и который готов держать маленький VPS с доменом.
Установка требует прохода по дашборду Meta — примерно час внимательной работы руками,
с 2FA, ролями и тумблером публикации. Инструкция расписана по шагам, каждый с проверкой
«что должно получиться»: [`docs/INSTALL.md`](docs/INSTALL.md).

Если вы отдаёте установку агенту (Claude Code и подобные) — начните с
[`CLAUDE.md`](CLAUDE.md): там записано, что агент делает сам, где он обязан остановиться
и что после этого предстоит сделать человеку.

## Чего этот пакет НЕ делает

- **Не рассылает сообщения по базе подписчиков.** Отвечать можно только тем, кто написал
  первым, — это граница платформы, а не недоделка. Такой функции не будет.
- **Не ведёт несколько аккаунтов.** Одна установка — один аккаунт Instagram. Второй
  аккаунт — вторая установка, со своим доменом и своим приложением Meta.
- **Не ведёт переписку.** На комментарий платформа разрешает ровно одно личное сообщение;
  дальше разговаривает человек.
- **Не проходит дашборд Meta за вас.** Вход, двухфакторная аутентификация, принятие роли
  и публикация приложения делаются руками владельца аккаунта. Ни один скрипт пакета этого
  не умеет и не пытается.
- **Не ходит в вашу CRM** и вообще ни в какие внешние системы, кроме Graph API Instagram и
  (если настроите) Telegram Bot API для аварийных сообщений.

## Установка коротко

```bash
git clone https://github.com/alexrexby/keywordIG.git
cd keywordIG
./scripts/install.sh ваш-домен.ru   # задаёт вопросы, отвечать нужно человеку
./scripts/doctor.sh                 # проверяет установку на реальность
```

A-запись домена должна указывать на эту машину ДО запуска, иначе не выдадут сертификат,
а выглядеть это будет как «ничего не работает». Порядок остальных шагов и семь ручных
действий в дашборде — в [`docs/INSTALL.md`](docs/INSTALL.md).

`doctor.sh` печатает у каждой проверки строку «чем может соврать» — это не отладочный
мусор, а самая полезная часть отчёта. Отказы этой механики молчаливые: приложение без
статуса «Опубликовано» не получает вебхуки ВООБЩЕ и без единой ошибки, а пустой ответ
Graph API `200` с пустым `data` означает «доступ урезан», а не «данных нет».

## Прочитать до первой кампании: чем рискуете вы

Пакет автоматизирует отправку сообщений в Instagram. Условия Meta вы принимаете сами,
заводя своё приложение, — это чисто. Но риск стоит назвать прямо:

- **Рискует ваш аккаунт Instagram, а не сервер.** Сотня автоматических сообщений
  незнакомым людям за час — ровно тот профиль поведения, который платформа ловит как спам.
  Последствия — ограничение или блокировка аккаунта, и они необратимее любой поломки
  сервиса.
- В пакете стоят **два разных предохранителя**: `IG_DISPATCH_RATE` ограничивает ТЕМП
  (сообщений в минуту, по умолчанию 20), `IG_DAILY_DM_LIMIT` — ОБЪЁМ (сообщений в сутки,
  по умолчанию 50). Это значения на ПЕРВУЮ кампанию: радиус любой ошибки ограничен
  объёмом, а поднять число, увидев живую механику, дешевле, чем объясняться с платформой.
- **Не выкручивайте лимиты в максимум первым делом.** Поднимайте после того, как увидели
  на своих данных, что автоответчик отвечает тем, кому надо, и тем, что надо.
- За содержание автоответов и за соблюдение условий Meta отвечает тот, кто поставил пакет
  и вписал в него свои тексты. Программа поставляется «как есть», без каких-либо гарантий
  (см. [`LICENSE`](LICENSE)).

## Поддержка: её нет

**Автор поддержки не оказывает** — ни установки, ни консультаций, ни ответов на вопросы
по вашей конфигурации. Это условие проекта, а не занятость: рассчитывайте, что чинить
будете вы или ваш агент.

Поэтому в пакет вложено то, что заменяет поддержку: `doctor.sh`, который проверяет
установку живьём и честно говорит, чего проверить не может; аварийные сообщения в
мессенджер, когда автоответы останавливаются; панель, показывающая очередь и причины
отказов; инструкция, написанная по живому проходу, с проверкой на каждом шаге; и карта
фактов платформы в [`.claude/journal/`](.claude/journal/INDEX.md) — то, чего нет в
документации Meta и что иначе добывается неделей отладки.

**Issues включены намеренно.** Ответа может не быть — и всё же это лучше закрытых issues:
единственный канал, по которому до автора дойдёт сообщение об уязвимости, важнее
видимости поддержки. Про уязвимости — [`SECURITY.md`](SECURITY.md).

Форк приветствуется. Если пакет вам пригодился и вы его доработали — это ваш пакет,
лицензия разрешает всё.
