# Журнал установки — факты, которых нет в коде

Картотека фактов о платформе Instagram/Meta, добытых живой работой, а не чтением
документации. Одна карточка — один самостоятельный факт. Здесь не хранятся секреты:
идентификаторы, токены и имена аккаунтов у каждой установки свои и живут в её окружении.

**Как читать:** сначала этот файл целиком (он маленький), потом только нужные карточки
из `cards/`. Грепать по всей папке «на всякий случай» смысла нет — в этом и смысл индекса.

**Как дополнять:** ваша установка обязательно наткнётся на то, чего здесь нет. Записывайте
это сюда же — файл `cards/<ГГГГ-ММ-ДД>-<слово>.md`, строка в индексе, формат карточки виден
в существующей. Полгода спустя это единственное место, где будет написано, почему что-то
сделано именно так: поддержки у пакета нет, и вспоминать будет некому.

Формат строки: `дата | тип | заголовок | теги | путь`.
